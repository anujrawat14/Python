# Important Methods of String

- lower()       → converts to lowercase
- upper()       → converts to uppercase
- islower()     → checks lowercase
- isupper()     → checks uppercase
- strip()       → removes outer whitespace
- replace()     → replaces text
- split()       → string → list
- join()        → list/iterable → string
- find()        → finds index, returns -1 if absent
- count()       → counts occurrences
- format()      → inserts values into string
- len()         → length of string
